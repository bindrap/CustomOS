# CustomOS Wallpapers

This folder contains wallpapers that will be included in your CustomOS installation.

## Location on Installed System

These wallpapers will be copied to: `~/Pictures/wallpapers/`

## Adding Your Own Wallpapers

Simply place your wallpaper images (PNG, JPG, etc.) in this folder before building the ISO.

Supported formats:
- PNG
- JPG/JPEG
- WebP

## Usage

After installation, you can:
1. Use the wallpaper selector: `ALT + Shift + W` (if script is available)
2. Manually set with: `swaybg -i ~/Pictures/wallpapers/your-image.png`
3. Configure in Hyprland config

## Included Wallpapers

Place your favorite wallpapers here! The build script will automatically copy them to the ISO.
